# 🚀 30 Days of Python Challenge

Welcome to my **30 Days of Python** learning lab! 🎒 As a **first-year university student**, this repository is my dedicated space to build a rock-solid programming foundation. 

My goal is to write **one completely fresh script every single day without a break**. Since I am just starting my coding journey, every day focuses on a brand-new concept, building up step-by-step from fundamental logic to neat little tools!

---

## 📈 My Learning Rules

*   🌱 **Zero to One:** Everything in this repository is built from scratch as I learn it in class and through self-study.
*   🚦 **Complete Variety:** Every day focuses on a completely new topic or basic problem-solving logic—no repetition!
*   🧩 **Standalone Scripts:** Every script runs independently so I can easily track my progress from Day 1 to Day 30.
